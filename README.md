# Figma AI Context Bridge

Figma AI Context Bridge exports selected Figma designs as AI-friendly JSON and exposes live design context to AI coding agents through a local MCP bridge.

The plugin is intentionally focused on AI agent workflows:

- export semantic, compact JSON for the current selection
- keep a local MCP bridge in sync with the active selection summary
- let agents search summary nodes and lazy-load detailed node data on demand

## Quick Start: Export AI JSON

1. Select a frame, component, or node in Figma.
2. Run `Export AI JSON`.
3. Use the downloaded JSON with your AI agent.

The exported JSON uses the `ai-optimized` schema and includes layout, CSS-like styles, text, positioning, component definitions, tokens, interactions, and implementation hints.

## Quick Start: MCP Bridge

There are two supported ways to get the MCP server:

- **GitHub repository clone**: best for developers who want source, tests, and scripts.
- **MCP server zip**: use `release/figma-ai-context-bridge-mcp-server.zip`, generated by `npm run release:mcp-pack`.

### Option A: GitHub Repository Clone

1. Build the plugin and MCP server:

   ```powershell
   npm install
   npm run build
   cd mcp-server
   npm install
   npm run build
   ```

2. Configure your MCP client to start the local server:

   ```json
   {
     "mcpServers": {
       "figma-design": {
         "command": "node",
         "args": ["mcp-server/dist/index.js"],
         "env": {
           "MCP_HTTP_PORT": "7800"
         }
       }
     }
   }
   ```

3. In Figma, run `Open AI Agent Bridge`.
4. Select or switch to the design you want the agent to inspect.
5. Click `Sync Detail to Agent` when the agent needs the full current-selection payload.
6. In the agent, call:
   - `get_connection_status`
   - `get_design_summary`
   - `get_design_selection`
   - `search_nodes`
   - `get_design_node`

Summary syncs automatically when the panel is open. `Sync Detail to Agent` pushes the heavier current-selection payload on demand. `Download AI JSON` and `Copy AI JSON` only export data for the user; they do not update MCP detail selection. `get_design_node` automatically requests detailed data for summary nodes. Keep the Figma panel open while the agent is working.

### Option B: MCP Server Zip

1. Extract `figma-ai-context-bridge-mcp-server.zip`.
2. Install and build:

   ```powershell
   cd figma-ai-context-bridge-mcp-server
   npm install
   npm run build
   ```

3. Point your AI agent MCP config at `dist/index.js` inside that extracted folder.
4. Open `Open AI Agent Bridge` in Figma.

## MCP Workflow

Recommended agent flow:

1. Check `get_connection_status`.
2. Read `get_design_summary`.
3. Ask the user to click `Sync Detail to Agent` for full current-selection detail when needed.
4. Read `get_design_selection` after detail sync.
5. Use `search_nodes` to find a target node.
6. Call `get_design_node({ nodeId })` to lazy-load that node's detail.
7. Use returned CSS, text, tokens, component definitions, positioning, and hints to implement or review code.

## Agent Setup

The MCP server is started by your AI coding agent, not by the Figma plugin. Keep paths relative to this repository unless your client requires absolute paths.

### Codex

Add this repository's `.mcp.json` to your Codex workspace configuration, or copy the same server entry into your global Codex MCP settings:

```json
{
  "mcpServers": {
    "figma-design": {
      "command": "node",
      "args": ["mcp-server/dist/index.js"],
      "env": {
        "MCP_HTTP_PORT": "7800"
      }
    }
  }
}
```

Restart Codex after changing MCP settings. Then open `Open AI Agent Bridge` in Figma and call `get_connection_status`.

### Claude Code

Add a local stdio MCP server named `figma-design` that runs:

```powershell
node mcp-server/dist/index.js
```

Set `MCP_HTTP_PORT=7800` in that server's environment. Restart Claude Code, open `Open AI Agent Bridge` in Figma, and use `get_design_summary` to confirm the connection.

### Cursor

Add the same stdio server entry to Cursor's MCP configuration:

```json
{
  "mcpServers": {
    "figma-design": {
      "command": "node",
      "args": ["D:/FigmaPlugin/mcp-server/dist/index.js"],
      "env": {
        "MCP_HTTP_PORT": "7800"
      }
    }
  }
}
```

Use an absolute path if Cursor launches outside this repository. Restart Cursor after editing MCP settings.

## Troubleshooting

- **MCP offline**: Start or restart your MCP client so it launches `mcp-server/dist/index.js`.
- **Port already in use**: If the existing process is a healthy `figma-design` bridge, new MCP server instances automatically proxy to it. If the port is held by another process, stop that process or change `MCP_HTTP_PORT`.
- **No summary**: Open `Open AI Agent Bridge` in Figma and switch selection once.
- **No selection detail**: Select the target nodes in Figma and click `Sync Detail to Agent`.
- **Lazy detail timeout**: Keep the panel open and call `get_design_node` again.
- **Large selection feels slow**: Summary sync is automatic; detail is lazy-loaded to avoid exporting the full tree by default.
